# API Reference

Base URL (docker-compose default): `http://localhost:8001`

**Auth**: every endpoint below except `/health` and `/ready` requires an `X-API-Key` header
matching `AEGIS_API_KEY`. A missing or wrong key returns `401`.

Interactive docs (Swagger UI) are auto-generated by FastAPI at `/docs` once the API is
running — this file is a narrative companion, not a substitute.

## Health

| Method | Path | Auth | Notes |
|---|---|---|---|
| GET | `/health` | none | Liveness only — no dependency checks. |
| GET | `/ready` | none | Readiness — executes `SELECT 1` against Postgres. |

## Golden cases & review

| Method | Path | Notes |
|---|---|---|
| POST | `/cases` | `{suite_id, question, context?, source, check_mode?, rubric_id?, tags?}`. Starts as `draft`. `404` if `suite_id` doesn't exist. |
| GET | `/cases?suite_id=&status=` | Filterable list. |
| GET | `/cases/{id}` | |
| POST | `/cases/{id}/reviews` | `{reviewer_name, proposed_answer}`. `409` if the case already has 2 submissions, or if `reviewer_name` already submitted once for this case. |
| GET | `/cases/{id}/reviews` | Returns `submission_count` and `reviewer_names` always; `submissions` (the actual text) is `null` until **both** independent reviews exist — the blind contract. |
| POST | `/cases/{id}/resolve` | `{decision: "approve"\|"needs_resolution", resolved_by, reference_answer?, notes?}`. `reference_answer` required when approving. `409` if fewer than 2 reviews exist yet. |
| POST | `/cases/{id}/retire` | Only from `approved`; `409` otherwise. |

## Calibration

| Method | Path | Notes |
|---|---|---|
| POST | `/human-labeled-samples` | `{case_id, candidate_answer, human_verdict, labeled_by}` — ground truth for calibration. |
| POST | `/calibration-runs` | `{rubric_id, judge_model_version, threshold?}`. Grades every labeled sample for that rubric with the real judge and compares to the human verdict. `409` if no samples exist. |

## Errors

All domain errors return a JSON body `{"detail": "..."}`:

| Status | Meaning |
|---|---|
| 401 | Missing/invalid `X-API-Key`. |
| 404 | Referenced entity doesn't exist. |
| 409 | A business-rule conflict (duplicate name, wrong case status for the action, review/calibration preconditions not met, a run already in progress). |
| 429 | Rate limit exceeded (on-change webhook only). |
| 503 | The LLM provider or the system under test is unavailable (e.g. missing `ANTHROPIC_API_KEY`) — surfaced here only when the failure happens outside an eval run's own graceful per-case error handling (e.g. the reference assistant itself, or calibration). |
